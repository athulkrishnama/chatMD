# Chat Wrapped

Chat Wrapped is a Chrome Extension that analyzes WhatsApp Web conversations and generates a fun "Chat Wrapped" with insights and statistics.

## Current Status
This project is currently in the initial phase. It includes a popup UI and a content script that successfully detects the currently opened chat name on WhatsApp Web.

**Note:** Analytics, AI, backend communication, message extraction, and actual Wrapped generation are not yet implemented. This phase ensures the architecture is sound and extension is cleanly integrated.

## Project Structure
- `src/popup`: Contains the React application for the Chrome extension popup.
- `src/content`: Contains the content script (`whatsappReader.ts`) injected into WhatsApp Web to interact with the DOM.
- `src/shared`: Contains shared types and utilities.
- `public`: Contains `manifest.json` and static assets.
- `vite.config.ts`: Configured to output a Chrome extension format.

## Development

### Prerequisites
- Node.js (>= 18)
- npm or yarn

### Installation
1. Run `npm install`
2. Run `npm run build`
3. Open `chrome://extensions` in your Chrome/Chromium browser
4. Enable **Developer Mode** (toggle in the top right corner)
5. Click **Load unpacked**
6. Select the `dist` directory generated by the build process
7. Open `https://web.whatsapp.com`
8. Open a conversation
9. Click the Chat Wrapped extension icon

## Scripts
- `npm run dev`: Start Vite development server (not typically used for Chrome extensions directly).
- `npm run build`: Build the extension into the `dist` folder.
- `npm run lint`: Run ESLint.
